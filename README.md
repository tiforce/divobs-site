# Divergence Observatory Website

Divergence Observatory is an initial static website foundation for a non-advisory market structure observatory.

The project is intentionally simple: no build system, no dependencies, no live billing, no APIs, no market data, no authentication, and no external services.

## Purpose

Divergence Observatory is positioned as an anonymous research-lab style observatory focused on:

- divergence
- hidden stress
- cross-asset structure
- regime shifts
- volatility
- macro/geopolitical transmission

It is a market structure observatory, not an investment advisory service, stock-picking service, or trading signal service.

## Local Usage

Open `index.html` directly in a browser.

No install step is required.

```text
index.html
```

You can also use a local static file server if desired, but the site does not require one.

## Non-Advisory Boundary

This project must not provide:

- investment advice
- personalized financial advice
- buy/sell/hold recommendations
- price targets
- trade alerts
- investment signals
- expected or guaranteed returns
- stock picks
- portfolio advice
- personalized recommendations

All content is for informational and educational use only. Users are responsible for their own decisions.
